# DOCUMENTATION branch

The thesis text lives here: `4 - Documentation/main.tex` and one folder per chapter. Build it with
`./compile_latex.sh` from the repository root.

This branch is never merged into another branch. Results and figures come from the research-question branches
(`RQ1-Prompt-Injection`, `RQ2-VectorDB-Flame`, `RQ3-BlackWall`); copy them in here when a chapter needs them.

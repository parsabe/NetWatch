\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

\noindent
Modern autonomous AI agents face significant security challenges where static safety filters and prompt engineering fail against dynamic runtime vulnerabilities, such as the Agent Runtime Authority Gap, Cache-Augmented Generation (CAG) poisoning, and GraphRAG topological attacks. This thesis presents \textbf{NetWatch}, a cybernetic guardrail architecture that balances applied mathematics (continuous Control Barrier Functions, Mahalanobis distance outlier detection, Fast Fourier Transforms, and Differential Privacy) with robust software engineering (tri-hook runtime API interception middleware, sandboxing, and provenance tracking).

\vspace{1em}
\noindent\textbf{Keywords:} AI Agent Security, Runtime Application Self-Protection (RASP), Control Barrier Functions, Mahalanobis Distance, GraphRAG Defense, Multimodal Guardrails.

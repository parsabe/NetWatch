\chapter{Related Work}
\label{ch:related_work}

\section{Vulnerabilities in Autonomous Agent Runtimes}
Recent advances in autonomous agents have revealed attack vectors such as Indirect Prompt Injection (IPI), Cache-Augmented Generation (CAG) poisoning, and Confused Deputy attacks where agents are tricked into misusing internal credentials.

\section{GraphRAG and Vector Knowledge Base Security}
Attacks exploiting vector databases and graph-based retrieval augmented generation systems via topological perturbation, competing relation injection, and embedding space poisoning.

\section{Mathematical Verification and Safe Execution Boundaries}
Constrained Markov Decision Processes (CMDP) and Control Barrier Functions (CBFs) used in robotic systems, and their emerging application to discrete LLM agent action spaces.

\section{Runtime Application Self-Protection (RASP) for AI}
Zero-Trust architectures for Non-Human Identities (NHI), ephemeral credential issuance, and dynamic API gateway middleware.

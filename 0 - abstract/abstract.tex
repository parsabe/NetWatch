\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

\noindent
Modern autonomous AI agents face significant security challenges where static safety filters and prompt engineering fail against dynamic runtime vulnerabilities, including Indirect Prompt Injection (IPI), the Agent Runtime Authority Gap, Cache-Augmented Generation (CAG) poisoning, and GraphRAG topological attacks. This thesis presents \textbf{NetWatch}, a cybernetic guardrail architecture that balances applied mathematics with robust software engineering across a tri-hook runtime interception gateway. For prompt injection defense (RQ1), NetWatch introduces \textbf{Horizon}, an end-to-end framework combining Stage~1 randomized keyed spotlighting with distributionally robust minimax bounds and Stage~2 deterministic guardrails featuring quarantined execution pools, Hoeffding-bounded majority voting, capability tokens, and SMT-verified noninterference policies.

\vspace{1em}
\noindent\textbf{Keywords:} AI Agent Security, Prompt Injection Defense, Horizon Architecture, Keyed Spotlighting, Minimax Game Theory, Distributionally Robust Optimization, Runtime Application Self-Protection (RASP), Control Barrier Functions.

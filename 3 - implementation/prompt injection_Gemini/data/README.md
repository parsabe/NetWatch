# Horizon Data Cards

This document details the datasets used for evaluating the Horizon defense pipeline across Stage 1, Stage 2, and the Direct/Jailbreak Layer.

All raw files are stored in `data/raw/` (gitignored). Processed splits are saved in `data/splits/`.

---

## 1. Stage 1 Datasets (Indirect Prompt Injection on Text/Documents)

### BIPIA (Benchmark for Indirect Prompt Injection Attacks)
- **Source URL**: `https://github.com/microsoft/BIPIA`
- **Version/Commit**: `main` (commit: `e695d3a` / latest)
- **License**: MIT License
- **Size**: ~2,500 test cases across email, QA, table, and summarization tasks.
- **Role**: Clean task corpus ($D, T, y^*$) for evaluating clean utility $U_\tau$, and injected documents for static ASR evaluation.
- **Download Date**: 2026-10-25

### LLMail-Inject
- **Source URL**: `https://huggingface.co/datasets/microsoft/LLMail-Inject`
- **Version**: SaTML 2025 Challenge release
- **License**: Microsoft Research License / CC-BY-4.0
- **Size**: ~1,200 human-written indirect injection attacks targeting email assistants.
- **Role**: Realistic shifted distribution $Q$ to measure empirical distribution shift $\rho$ and evaluate adaptive stress-testing.
- **Download Date**: 2026-10-25

### Synthetic Canary Benchmark (Stage 1 Paired Suite)
- **Generated by**: `scripts/download_data.py`
- **Size**: 1,000 injected documents + 1,000 clean documents with ground truth references.
- **Categories**: `ignore_previous`, `fake_system`, `roleplay`, `polite`, `completion`.
- **Canary Pattern**: `CANARY-[HEX]` generated via CSPRNG (`secrets.token_hex`).

## 2. Stage 2 Datasets (AgentDojo Tool-Use Benchmark)

### AgentDojo
- **Source URL**: `https://github.com/eth-sri/agentdojo` (Package: `agentdojo`)
- **Version**: Built-in benchmark suites
- **License**: Apache 2.0
- **Suites**: `workspace`, `slack`, `travel`
- **Attack Types**: System Prompt Leakage, Unauthorized Tool Execution, Parameter Tampering, Data Exfiltration.
- **Role**: Built-in attacks serve as attack styles $k$ for the Stage 2 Sion game matrix $\bar{\ell}[k, \theta]$.
- **Conformal Calibration Labels**:
  - Benign: User-task tool calls (ground truth from AgentDojo task specification).
  - Dangerous: Injection-task tool calls triggered by untrusted content.

## 4. Evaluation Splits & Design

- **Fit Split** (50%):
  - Used strictly for selecting $\tau^*$, solving $\pi^*$, calibrating $\hat{\lambda}$ (Conformal Risk Control), and finding $\pi^*_{\text{Horizon}}$.
- **Report Split** (50%):
  - Used strictly for evaluating and reporting $\bar{\mathcal{R}}_\tau(\rho)$, $V_1(\rho, \eta)$, $V_{\text{Horizon}}$, empirical loss, and empirical conformal risk.
  - **Rule**: Never report a metric computed on the split used to choose the policy/thresholds.
- **Paired Evaluation Design**: Every attack sample in the report split is evaluated across all defense variants and configurations under identical keys and random seeds.

## Notes
- **bipia**: WebQA and Summarization subsets need separate source download (license); not used.
- **llmail_inject**: Only the labelled phase-2 submissions (≈69 MB); the 1.6 GB raw dumps are not fetched.
- **harmbench**: Original CSV from the authors' GitHub (the walledai HF mirror is gated).
- **xstest**: Public copy of XSTest v2 (the walledai mirror is gated).
